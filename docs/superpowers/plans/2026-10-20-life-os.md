# Life OS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a personal life command center web app with a hub-and-spoke layout, kanban boards per life area, and a dashboard that shows the full picture at a glance.

**Architecture:** Express backend serves the React SPA and a REST API; Prisma manages a SQLite database on a Railway persistent volume. Auth is single-user JWT. The frontend uses React Router for navigation between Dashboard and area Kanban views.

**Tech Stack:** Node.js + Express + Prisma + SQLite (backend) · React + TypeScript + Vite + Tailwind CSS + @hello-pangea/dnd (frontend) · Vitest + supertest (tests) · Railway (deployment)

**Spec:** `docs/superpowers/specs/2026-10-19-life-os-design.md`

## Global Constraints

- Dark theme only: background `#0f172a`, card surface `#1e293b`
- Six fixed areas (IDs hardcoded): `job1` `job2` `university` `learning` `sports` `personal`
- Area accent colors: job1=`#6366f1`, job2=`#8b5cf6`, university=`#10b981`, learning=`#f59e0b`, sports=`#14b8a6`, personal=`#ec4899`
- Urgency levels: `low` | `medium` (default) | `high`
- Due dates stored as ISO date strings `YYYY-MM-DD`; comparison uses browser local date
- Completion timestamp stored when card moves to a Done column; cleared if moved back out
- Done cards with `completedAt` older than 90 days are archived (excluded from board and stats)
- Cards are permanently scoped to one area — no cross-area moves
- Learning columns: `Backlog` · `In Progress` · `Done`; Sports: `Planned` · `Done`; all others: `To Do` · `In Progress` · `Done`
- **UI tasks:** invoke `frontend-design` skill before writing any component
- Mobile-first: sidebar on desktop (`lg:`), bottom tab bar on mobile

## Review Focus

- Card with no due date moved to Done — `completedAt` must be set; "Done today" stat must count it
- Card moved back from Done to In Progress — `completedAt` must be cleared; "Done today" must not count it
- Urgency sort with no due date — falls back to High > Medium > Low, then newest `createdAt`; dashboard shows correct card
- Archived card (completedAt > 90 days ago) — must not appear in board columns or any stat tile
- JWT expiry — expired token returns 401; client redirects to `/login` without crashing
